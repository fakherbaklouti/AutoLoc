# AutoLoc

Projet AutoLoc - Architecture des SI & Spring

## Description

AutoLoc est une application de gestion de location automobile développée
dans le cadre du module Architecture des SI & Spring.

## Acteurs

- Client
- Agent d’agence
- Responsable d’agence
- Administrateur

## Environnement de développement

- Java 17
- IntelliJ IDEA
- Lombok
- MySQL 8
- MySQL Workbench
- Postman
- Git
- GitHub

## Base de données

Nom de la base : `autoloc_db`

Serveur : `localhost`

Port : `3306`
